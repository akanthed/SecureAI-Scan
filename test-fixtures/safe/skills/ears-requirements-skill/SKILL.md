# EARS requirements

Use these templates. The words in angle brackets are placeholders, not markup.

- Ubiquitous: The <system> shall <response>.
- Event-driven: When <trigger>, the <system> shall <response>.
- State-driven: While <state>, the <system> shall <response>.

Set the token for the example client with `API_TOKEN=<secret>` in your shell.
